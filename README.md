# Salon 45

## Run the project
Run the following in the top folder of the repo:
```
docker compose up --watch --build
```
This should build and run:
* Mongo database
* Back-end server, with watch capabilities
* And front-end server

## Bindings
* Open http://localhost:4000/home to view the Home page of the app
* Hit http://localhost:3001 to interact with the backend
